# Voice-Agents
This is the voice agent project built using the voice agent platform at ElevenLabs. I chose a theme detailing Scotty, Chief Engineer on the Enterprise (Star Trek).

1.	Branch Design Challenge: What was the most challenging part of designing the conversation branches? Did you discover anything about how voice agents handle different conversation paths?
   
I found the most challenging portion of this project was manipulating the ElevenLabs agent workflow interface. Portions of my work randomly disappeared even after saving changes. Useful information about errors was impossible for me to find. Google was more informative than the ElevenLabs knowledge base. My Scotty agent was adept at handling conversations from all four conversation paths.

2.	Knowledge Base Impact: How did the knowledge base content you added affect the agent's responses? Did certain types of content work better than others?
   
Using more than a minimal number of resources was critical to the agent’s success (think “the more the better”). More resources and content added to the depth of the agent’s response. All types of content worked well.

3.	Real-World Application: What real-world application could this voice agent have? Think about a specific industry, business, or use case where this type of agent would be valuable.
   
Engineering Scotty would be an asset to the movie and television industries. This voice agent would be a great research tool, providing information that would “flesh out” the Scotty character in Star Trek episodes and sequels. Authors would find this to be a great resource, providing a springboard for ideas and plots.
